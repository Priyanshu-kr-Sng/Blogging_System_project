# Django Blogging Platform

A real-world, feature-rich blogging platform built with **Django**, designed to demonstrate production-oriented backend development, authentication, authorization, database relationships, file handling, dashboards, and deployment.

The project implements a **multi-role access control system** with Admin, Manager, Editor, and Author roles. Users receive different capabilities based on their assigned groups and permissions.

## Key Features

* 🔐 **Multi-role authentication & authorization**

  * Admin, Manager, Editor, and Author roles
  * Django Groups & Permissions
  * Custom permission checks and role-based access control

* 📝 **Blog & Category Management**

  * Complete CRUD operations for posts and categories
  * Unique slug generation and automatic slug prepopulation
  * Featured and recent posts

* 💬 **Comment System**

  * Authenticated users can add comments
  * User-to-post relationships
  * Permission-controlled interactions

* 📊 **Role-Based Dashboards**

  * Dedicated Manager and Editor dashboards
  * Post and category statistics
  * Data tables and management actions

* 🔎 **Search & Pagination**

  * Search posts by relevant content
  * Search term retained in the search field
  * Paginated post listings

* 🖼️ **Media & Static Files**

  * Image upload and management
  * Django media/static file configuration

* ⚙️ **Django Admin Customization**

  * Customized admin listings and management interfaces

* 🚀 **Deployment**

  * Configured and deployed using **PythonAnywhere**
